# 珠海高新区统侨科 · 加班统计与补贴核算

离线网页应用，用于统侨科合同制职员加班情况的登记、月度汇总与补贴核算，并**按指定模板**一键导出 Excel（公示表 + 发放表）。

> **v2 更新**：个人登录（数据按人隔离）· 起止时间自动换算时长 · 移动端响应式优化。

## 特点

- **完全离线**：单个文件夹，双击 `index.html` 即可在浏览器使用，无需联网、无需安装、无需服务器。
- **零第三方依赖**：Excel 由自带的小型生成器（`xlsx.js`）生成，不依赖任何 CDN 或外部库。
- **个人登录 · 数据按人隔离**：输入「姓名 + 部门」进入，所有记录按登录人独立存储；同一姓名即同一账号，可随时退出切换不同人分别记录。
- **时长自动换算**：录入只需填**起始时间**与**终止时间**，系统自动算出本次加班时长（支持跨天，如 23:00–01:00 = 2 小时），不再手填小时数。
- **移动端优化**：窄屏下表单自动单列、表格可横向滑动、按钮加大，手机上也能顺畅填报。
- **按模板导出**：导出的 `.xlsx` 含两张表，严格对齐单位模板：
  - **公示表**：按日期逐条记录（部门、姓名、加班日期、工作日/双休日/法定节假日时长、起止时段、事由、小计）。
  - **发放表**：按人汇总（工作日/双休日/法定节假日累计时长、加班补贴金额、合计），含规则备注行。
- **数据存本机**：所有记录保存在浏览器 `localStorage`；支持 JSON 备份与导入，换电脑/清缓存前请先导出备份。

## 补贴计算规则

| 类型 | 标准 | 当天封顶 |
|---|---|---|
| 工作日加班 | 15 元/小时（**不足 1 小时不计，满 1 小时按整段时长**） | 80 元 |
| 双休日加班 | 20 元/小时 | 160 元 |
| 法定节假日加班 | 30 元/小时 | 240 元 |

“当天补贴最高”按**每条记录（自然日）**封顶，再按月汇总；同一天同一类型记一条，跨类型分别计。
该规则与模板发放表样本（徐梦华：工作日 7h、双休日 5h、补贴 205 元）完全吻合，已用模板真实数据验证通过。

## 使用方法

1. 克隆或下载本仓库到本地。
2. 双击打开 `index.html`（推荐 Chrome / Edge / Firefox；手机浏览器亦可）。
3. **登录**：填写「姓名 + 部门」后点「进入」（同一姓名即同一账号，可退出切换）。
4. 在「统计设置」选择**统计月份**、填写填报单位 / 公示时间 / 制表日期。
5. 在「录入加班记录」选择日期、类型，填写**起始时间、终止时间、事由**，本次时长自动换算；点「添加记录」。
6. 查看「本月记录」与「月度汇总（本人）」，确认无误后点**导出 Excel**。

> 提示：数据仅存在你打开页面的那台电脑浏览器中（按登录人隔离）。如需在多设备使用，请用「导出数据备份(JSON)」迁移，再用「导入数据备份(JSON)」恢复。

## 文件说明

- `index.html` — 页面、登录屏与样式（含移动端响应式）
- `app.js` — 登录态、数据隔离、时长换算、录入/汇总/补贴计算、导入导出逻辑
- `xlsx.js` — 纯 JS 的 XLSX 生成器（stored zip + CRC32，无外部依赖）
