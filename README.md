# 珠海高新区统侨科 · 加班统计与补贴核算

离线网页应用，用于统侨科合同制职员加班情况的登记、月度汇总与补贴核算，并**按指定模板**一键导出 / 导入 Excel（公示表 + 发放表）。

> **v3 更新**：个人登录（部门默认统战科、标题随科室变动）· 起止时间自动换算时长 · 补贴按小时向上取整 · 移动端响应式 · 支持导入模板 Excel 自动识别录入。

## 在线使用（推荐手机直接打开）

- **GitHub Pages 在线版**：https://ivanxxxxxxxxx.github.io/zhuhai-tongqiao-overtime/ （仓库已设为公开，任何人可访问，与政务服务题库同一方案）
- 数据存在你手机/电脑浏览器本地（localStorage），不进仓库、不上传服务器；公开仓库仅暴露代码，不泄露任何真实加班记录。

## 特点

- **完全离线**：单个文件夹，双击 `index.html` 即可在浏览器使用，无需联网、无需安装、无需服务器。
- **零业务依赖**：Excel 由自带的小型生成器（`xlsx.js`）生成，并引入 `vendor/xlsx.full.min.js`（SheetJS）用于**导入读取**，均无需任何外网 CDN。
- **个人登录 · 数据按人隔离**：输入「姓名 + 部门」进入，所有记录按登录人独立存储；同一姓名即同一账号，可随时退出切换不同人分别记录。部门默认「统战科」，主界面标题随部门变动（如登录部门填「xx科」，标题即「珠海高新区xx科加班统计与补贴核算」）。
- **时长自动换算**：录入只需填**起始时间**与**终止时间**，系统自动算出本次加班时长（支持跨天，如 23:00–01:00 = 2 小时），不再手填小时数。
- **移动端优化**：窄屏下表单自动单列、表格可横向滑动、按钮加大，手机上也能顺畅填报。
- **按模板导出 / 导入**：导出的 `.xlsx` 含两张表，严格对齐单位模板（公示表逐条、发放表按人汇总）。导入时选择统侨模板（含「公示表」工作表）即可**自动识别并录入**相应信息，同名同月数据覆盖更新、不影响他人。
- **数据存本机**：所有记录保存在浏览器 `localStorage`。

## 补贴计算规则（v3 调整）

| 类型 | 标准（不满 1 小时不计，满 1 小时后按小时向上取整） | 当天封顶 |
|---|---|---|
| 工作日加班 | 15 元/小时（1.1 小时按 2 小时算，以此类推） | 80 元 |
| 双休日加班 | 20 元/小时 | 160 元 |
| 法定节假日加班 | 30 元/小时 | 240 元 |

“当天补贴最高”按**每条记录（自然日）**封顶，再按月汇总；同一天同一类型记一条，跨类型分别计。该规则与模板发放表样本（徐梦华：工作日 7h、双休日 5h、补贴 205 元）完全吻合，已用模板真实数据验证通过。

## 使用方法

1. 打开链接或双击 `index.html`（推荐 Chrome / Edge / Firefox；手机浏览器亦可）。
2. **登录**：填写「姓名 + 部门（默认统战科）」后点「进入」（同一姓名即同一账号，可退出切换）。主标题会随部门变动。
3. **录入**：选日期、类型，填**起始时间、终止时间、事由**，本次时长自动换算；点「添加记录」。
4. **统计设置**：选「统计月份」与「填报单位」；公示时间、制表日期在**导出时自动填当天**，无需手填。
5. **导入 / 导出**：
   - 「导出 Excel」：按模板生成当月「公示表 + 发放表」直接下载。
   - 「导入 Excel（按模板）」：选择统侨模板（含「公示表」工作表），自动识别部门/姓名/日期/三类时长/起止时段/事由并录入系统。

> 提示：数据仅存在你打开页面的那台设备浏览器中（按登录人隔离）。

## 文件说明

- `index.html` — 页面、登录屏与样式（含移动端响应式）
- `app.js` — 登录态、数据隔离、时长换算、补贴计算、Excel 导入解析、导出逻辑
- `xlsx.js` — 纯 JS 的 XLSX 生成器（stored zip + CRC32，无外部依赖）
- `vendor/xlsx.full.min.js` — SheetJS，仅用于导入时读取 `.xls` / `.xlsx`
