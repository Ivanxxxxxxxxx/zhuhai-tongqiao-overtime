## 使用说明

1. 用浏览器打开上面的链接 → 填「姓名 + 部门」进入（部门默认统战科）。
2. 录入加班：选日期、选类型（工作日 / 双休日 / 法定节假日）、填 **起始时间 + 终止时间**（24 小时制，时长自动按向上取整换算）→ 填事由 → 添加。
3. 顶部「退出 / 切换」可换人，数据按姓名隔离存储在本机浏览器。
4. **导出 Excel**：点「导出 Excel（公示表 + 发放表）」，按统计月份生成该月表格（数据填入内置统侨模板）。
5. **导入 Excel**：选择按统侨模板导出的 `.xls/.xlsx`（含「公示表」工作表）即可自动识别并录入；同名同月数据覆盖更新，不影响他人数据。

> 数据保存在本机浏览器（localStorage），换设备/清缓存不联网同步。如需多人汇总到一台机器，可各自导出后合并，或后续接入云服务。

## 补贴计算规则

- **工作日加班**：不满 1 小时不计；满 1 小时后按整小时向上取整，15 元/小时，**当天补贴最高 80 元**。
- **双休日加班**：20 元/小时，**当天补贴最高 160 元**。
- **法定节假日加班**：30 元/小时，**当天补贴最高 240 元**。
- “当天补贴最高”按自然日封顶；同一天同一类型记一条，跨类型分别计。
- 与模板发放表样本（徐梦华 工作日 7h、双休日 5h、补贴 205 元）完全吻合。
